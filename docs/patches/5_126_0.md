# 5.126.0

*Released 26 November 2026*

You can add a named crew member to a call straight from the Call dialog, without going through Crew Finder.

Press **＋ Add Crew** next to Find Crew, type a name and press Check. You get the same panel as clicking a name in Crew Finder: photo, reliability and the ±48h timeline, checked against the call and every call it feeds. Then **+ Add** or **✓ Add & Confirm**.

A clash with an overlapping shift, or unavailability, disables the buttons, because SmartStaff won't book it. Fatigue, venue-change and 24-hour warnings, an unanswered offer that clashes, a clash on a call this one feeds, and a call that is already full all need one extra click (**Add anyway**). Someone already on the call is shown with their status instead.

This also works on full calls, which never appear in Crew Finder's Unfilled Calls list. Admins only.
