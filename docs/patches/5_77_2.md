# 5.77.2

*Released 21 October 2026*

Importing an estimate works again. Since 5.76.0 an import stopped partway through with "Unexpected error" after creating the booking and its calls, so the booking's rate card was never saved and the import was not logged.

- **Estimate import fixed:** the import now completes, saves the booking's rate card and logs the import, so the duplicate check catches a re-import.
- **If you imported an estimate since 20 October and saw "Unexpected error":** the booking and its calls were created. Check the booking's rate card, and don't import that estimate again.
