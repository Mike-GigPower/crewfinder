# 5.22.0

*Released 31 August 2026*

Adds a Miscellaneous licence group for certifications outside the WorkSafe
high-risk-work schedule and the VicRoads driver classes: Police Check,
ISO 45001 Auditor, and Responsible Service of Alcohol.

All three record an expiry date and appear everywhere existing licence types
do — the Add Licence dropdown, Licence Triage, and the Crew Finder licence
filter with holder counts and expiry badges.

Further codes can be added to the group through the Licence Catalogue editor
without a release.

Also fixes Licence Triage, which validated codes against a frozen list rather
than the live catalogue. Any licence type added after the original catalogue
seed was assignable in the Licences tab but rejected as "invalid code" in
triage — the one screen built to assign them.
