# 4.10.3

*Released 22 July 2026*

THE GOAT — v4.10.2 -> v4.10.3

Three changes this release: a richer crew-details header, A4-optimised crew-list printing, and a fix that makes CrewFinder's induction warnings actually fire for named venues. One of them (get-crew.php) is a SmartStaff endpoint — deploy it to test → prod before the DMG build. The other two ship in the app binary. Full order under Deployment below.

Crew details header — photo, reliability, Work Visa flag. The Administration crew-details dialog now opens with a header banner: the crew member's photo top-right beside their name, their Late / No-show reliability (12-month and all-time — the same figures as the CrewFinder rollover), and, for working-visa crew, a Work Visa badge carrying the visa's expiry, colour-coded expired / expiring the way induction badges are.

Crew Lists — optimised for A4. The printable Call / Door lists now declare A4 with sensible margins, repeat the column header on every page a long call spills onto, never slice a crew row across a page break, and print the grey header shading reliably. Font size and the write-in row height are unchanged, so On / Break / Off stay hand-writable.

CrewFinder — induction warnings fire for named venues. A crew member whose induction for the booking venue is expired or expiring now shows the red / amber note next to their name, for every venue in the controlled list — not just the handful whose name happened to match their code.
