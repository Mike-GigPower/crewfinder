# 5.108.0

*Released 17 November 2026*

Import Times now shows each call's date and time beside its name. Calls with the same name on one booking, such as two Show Calls, can now be told apart. Performance now shows crew-pay margin for selected admin accounts: weekly against last year, by customer, booked ahead (estimated) and for the financial year, against a 40% target.
