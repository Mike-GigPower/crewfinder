# 3.19.2

*Released 9 July 2026*

THE GOAT — v3.19.1 -> v3.19.2

Frontend only. No PHP, no backend changes.

Change

Fix the in-app "Download update" banner link. It used target="_blank", so clicking it opened a
new blank tab and Chrome silently blocked the DMG download (the tab just sat blank, nothing landed
in Downloads). Removing target="_blank" makes the link download in place — the same behaviour as
pasting the release URL into the address bar, which works.

Note: this fix only takes effect once a user is running 3.19.2 or later. Anyone updating FROM an
older build still needs the manual workaround for that one hop: right-click "Download update" ->
"Save Link As...", or paste the release DMG URL into the address bar.
