# 4.21.0

*Released 5 August 2026*

Search the Recruitment tab. A search box now narrows the current pile by name, reference, email or phone. Phone matching ignores spacing, so 0419 123 333 is found by typing 419123. If the person you're after is in a different pile, a quiet line says how many matches are elsewhere with one click to widen.

Sortable columns. Name, Status and Reference headers now sort, cycling ascending, descending, then back to normal order. Sorting by Status inside a pile puts the longest-waiting candidates first, so anyone who has been sitting too long rises to the top. On the All pile it groups by stage and orders each group by age.

Clearer wording throughout. Buttons now read as actions and piles read as states: "Send to EH" moves a candidate into "With EH". Also "Details in", "Ready to convert", "Crew", "Put on hold", "Mark not suitable" and "Return to New". Both the detail panel and the batch action bar use the same wording.

Status colours mean one thing. Colour now indicates condition rather than stage: green for Crew, amber for On hold, grey for Not suitable and Withdrawn. Pipeline stages are neutral, with the stage shown by name and by its position in the filter row.

Confirmations panel fixes. The eligibility row now reads "Over 18", matching what the details form actually asks. WWCC pills wrap within their cell instead of overlapping the next column.
