# 5.79.0

*Released 21 October 2026*

The call and booking dialogs now have tabs along the top for information, and keep only actions in the buttons along the bottom. Both open on Details every time.

- **Call dialog tabs:** Details, Booked Crew, Responses (Admins) and Crew Notes. Booked Crew shows how many are booked against the number required.
- **Filter and order the booked crew:** chips for each status on the call (Confirmed, Pending, Declined and so on), with a count on each, and an order by status or by name.
- **Booking dialog tabs:** Details, Calls, Crew Notes, Call feeds and Crew bosses (Admins). Call feeds and Crew bosses work as before, now from their own tabs.
- **Crew Notes in THE GOAT:** read the notes crew see in Crew Hub without leaving THE GOAT, with who posted them, when, and how many crew have acknowledged. On a call you see that call's notes and the booking's notes. Posting stays in Crew Hub, through the Post in Crew Hub link on the tab.
- **The dialog stays the same size** when you switch tabs, so the buttons never move. Back from a call returns you to the booking's Calls tab.
