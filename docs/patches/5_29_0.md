# 5.29.0

*Released 3 September 2026*

Induction chips on the Recruitment list. A red MVL and a blue MOP now show against applicants who have submitted their Marvel and Melbourne Park inductions — visible in the list without opening anyone. Of the applicants with any induction on file, 85 have Melbourne Park and 72 have Marvel, so most rows that matter carry one or both. A chip only appears once the certificate and its date are actually in; a half-filled entry doesn't earn one.

Phone numbers read like phone numbers. Mobiles as 0412 345 678, landlines as (03) 9376 9500, wherever a number is displayed. Numbers stored as +61… render the same way, so the format is consistent regardless of how it was entered.

Nothing stored changes, and click-to-dial still uses the exact number on file — a number that isn't recognisably Australian is shown exactly as it was entered rather than reshaped into something that looks local.
