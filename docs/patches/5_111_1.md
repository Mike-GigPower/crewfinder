# 5.111.1

*Released 19 November 2026*

Backups no longer make a full call look like it needs chasing.

- **Schedule and Operations:** a backup who hasn't answered a time change no longer turns a full call amber, and no longer appears on the Acknowledgements outstanding list. A backup doesn't hold a place, so there is nothing to chase. This part went live on the server on 18 November, before this build.
- **Call dialog:** a backup with an unanswered time change shows a small grey **time change not answered** tag, so you can see it before promoting them. Confirmed crew keep the amber **awaiting re-confirm** badge.
- **Responses tab:** the same backup's "time changed — no answer yet" line is grey, not amber.
- **Schedule tooltip:** a new line says how many backups haven't answered a time change.
- If a backup is promoted while the time change is still unanswered, the call is flagged again, because they now hold a place.
