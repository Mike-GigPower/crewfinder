# 3.2.0

*Released 22 May 2026*

# THE GOAT v3.2.0 — Release Notes
**22 May 2026**

---

## 🆕 New Features

### Estimate Import (GigPower → SmartStaff)
- New **Estimate Import** tab — drop a GigPower JSON export to create a SmartStaff booking and all calls automatically
- Smart fuzzy matching for Customer, Contact, Onsite Contact and Venue against SmartStaff records — handles name reversals (e.g. "Smith, John" ↔ "John Smith"), punctuation and case differences
- Shadow text shows imported values alongside each dropdown for verification
- Duplicate detection — blocks re-import of already-imported estimates
- Import history log with links back to created bookings
- Schema version support for GigPower export v1.0 and v1.1 including new `onsite_contact_phone` field

### Crew Utilization — Unavailability Display
- Crew-entered leave and unavailability periods now shown as **purple blocks** in the utilization grid
- Unavailability data scraped separately from SmartStaff and cached independently (4hr TTL)
- Purple blocks also appear in Crew Finder timeline for conflicted/unavailable crew
- Crew marked as unavailable are correctly excluded from availability search results
- Purple "Unavailable" swatch added to legend

### Scheduling Clash Detection
- When a booking is expanded in the Schedule tab, crew are cross-referenced across all open calls
- Any crew member double-booked at overlapping times is flagged
- **Clashing call blocks** turn orange with a pulsing glow
- **Clashing crew names** shown in red with ⚠ prefix below the status line
- `⚡ N clashes` badge displayed inline on affected calls

---

## ⚡ Performance

### Server-Side Forecast Cache
- Forecast data now pre-loaded in background on login and written to `forecast_cache.json`
- Subsequent Utilization loads served from disk — effectively instant
- Shift cache (1hr TTL) and unavailability cache (4hr TTL) run as separate background jobs
- Cache age indicator next to ⟳ Refresh button shows freshness status
- Stale cache served immediately while background refresh runs — no more waiting
- Request timeout reduced 30s → 10s; parallel worker pool flattened for better throughput

## 🐛 Bug Fixes

- Fixed `ss_login` → `create_ss_session` reference error in `reauth_ss_session` causing 500 on session expiry

- Fixed schema version validator to accept both `"1.0"` and `"1.1"`
- Fixed unavailability filter — now correctly identifies booking entries using `@`, en-dash, em-dash, and ` - ` separators; genuine leave entries (e.g. "On leave") pass through correctly
