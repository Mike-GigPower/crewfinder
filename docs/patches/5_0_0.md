# 5.0.0

*Released 12 August 2026*

Navigation rebuilt. Ten tabs in a scrolling row become five groups — Today, Bookings, Crew, Recruitment, Admin — each opening on the view you used last. Bookings and Crew show a second row of views; the others don't, so nothing costs space it hasn't earned. The scroll arrows are gone.

Command palette. Press ⌘K anywhere to jump straight to any view. Type a few letters — "cf" finds Crew Finder, either spelling of utilisation finds Crew Utilization.

Crew filters now carry. Set a name search or a group on Crew Utilization and switch to Inductions: the same filter is already applied. Narrow to a set of people once, then look at them through different lenses.

My Status has moved out of the tab row into the top bar, beside Sign out.
