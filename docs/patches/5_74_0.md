# 5.74.0

*Released 14 October 2026*

Convert to crew can now update a returning crew member's existing SmartStaff record instead of creating a second one.

When **Convert to crew** finds a possible existing crew member (same email or a similar name), you now choose what to do. Pick which matched person it is, then choose **Update the existing record** (the default) or **Create a NEW crew record anyway**. Create works exactly as before.

**Update** shows each detail that differs, with **Current** and **New** side by side. New values are ticked; untick any row to keep the current value. Details that already match aren't shown, and a blank onboarding value never overwrites what's on file. Names are never changed here: if they differ you'll see a note, and you can fix it in **Manage Crew**.

Pressing **Update crew member** also:

- reactivates the record if it was inactive
- adds the onboarding notes **below** the existing notes, under a dated "Re-onboarded" line — old notes are kept
- replaces the signed contract and the photo (the old photo is kept as a backup)
- adds licences, inductions and visa details, as a new conversion does
- resets the password to the temp password and sets their login username back to their **existing EIN**, then sends the welcome email

The EIN never changes. If they only said they'd worked with Gig Power before and no record matched, Convert works as it did.
