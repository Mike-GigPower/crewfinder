# 5.42.0

*Released 11 September 2026*

Crew can now record what someone should do for them in an emergency — an
adrenaline auto-injector, epilepsy, asthma — and where they keep their
medication. They write it themselves in Crew Hub under More → Emergency
Information, and can change or remove it at any time.

Manage Crew gains an Emergency tab, plus a first-aid marker beside the EIN and
ID for anyone who has recorded something. Opening the tab is a disclosure and is
logged: the crew member can see who opened their card and when. Ops cannot edit
a card — if something is wrong, ask them to correct it.

Admin and Operations only. Leadership is not included.

Crew bosses are not included yet. That depends on the boss actually being set on
a call, which currently happens on about one call in twelve.

If you are elevated to admin, the Emergency tab will refuse to open and tell you
to drop elevation — so the access log names you rather than the admin account.
