# 5.21.0

*Released 28 August 2026*

Crew Finder now hides crew who have already answered — booked or declined — with a count in the header showing how many were removed. Both toggles live under Filters and stay set for the session. On a multi-call search, someone is only hidden when settled the same way on every selected call, so a person booked on a load-in still shows for the load-out.

More room for names: the shift-bar legend now appears only in Timeline view, ALREADY BOOKED starts collapsed, and a new Focus button hides the top bars entirely (Esc, or any navigation, brings them back). The TEST banner is never hidden.

Create Booking scrolls properly again — the "+ Add Call" button no longer clips off the bottom of the Calls card on a short window.

The Today tab under the Today group is now called Operations, so the two are no longer both "Today". Typing "today" in the command palette still finds it.

New Gig Power logo throughout — transparent artwork in full colour, replacing the version with a baked-in black background.
