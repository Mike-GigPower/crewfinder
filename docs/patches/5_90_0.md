# 5.90.0

*Released 28 October 2026*

**Events now have their own view.** All Bookings has a new Events button next to List and Calendar: search events by name, see how many bookings each one has, show archived events, and make a new one. Click an event to open it. The Bookings tab lists each booking with its dates, venue, how many places are filled, and B / T markers for Broadcast and Travel calls. The Crew tab lists everyone booked across the event once, with how many calls and days they are on. The Notes tab holds the event's notes. Admins can add and remove bookings, rename the event, edit its notes, and archive it once it is empty. The event name on a booking's Details tab now opens the event.
