# 5.57.0

*Released 21 September 2026*

Groundwork for live check-in — a replacement for the Google Sheets timesheet, being piloted before anyone relies on it.

Bookings now carry a **Live check-in** setting, shown below the calls in the booking dialog and in the All Bookings panel.

During the pilot it is switched by one account only, and a booking can only be **Off** or **Shadow**. In Shadow, the Google Sheet is still generated and is **still the record for payroll** — the new check-in runs alongside it so the two can be compared.

Nothing changes for any booking until it is switched.
