# 5.14.0

*Released 24 August 2026*

A new Performance view under Today, for Joe, Rich and Monty.

Weekly invoiced hours and revenue for the last 52 weeks, with the same period last year overlaid for comparison. Work that has been delivered but not yet invoiced shows as a separate hatched band, so the gap between doing the work and billing it is visible for the first time.

Revenue is broken down by customer — the eight largest individually, everything else rolled up — and each segment opens that customer's own history. A yield table shows revenue per hour alongside the hours behind it.

Figures are invoiced revenue attributed to the date the work happened, not the date it was billed, so they will not match a monthly accounting figure. The forward 60-day view arrives in the next release.
