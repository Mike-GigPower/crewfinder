# 4.17.1

*Released 3 August 2026*

Fixes a crash that stopped Crew Finder searching any venue with a controlled induction, and a display fault that left Manage Inductions showing an empty catalogue. Both trace to the same cause: induction data arriving in a different shape than the code reading it expected. No database or SmartStaff change.
