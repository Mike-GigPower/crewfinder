# 5.128.0

*Released 27 November 2026*

New crew members now get their own random temporary password instead of a shared one. Convert to crew, Update existing record and Administration > Add Crew Member each generate a fresh 10-character password, send it in the welcome email and show it to you once. Resend welcome email now sets a new temporary password before sending — the old one stops working — and if the email can't go out you're shown the new password to phone through. If the crew member has already chosen their own password, ask them to use Forgot password instead.
