# 3.4.2

*Released 28 May 2026*

Bug fix: when multiple crew were selected in Crew Finder and "Send SMS" was clicked, only one crew member received the message. SmartStaff expects `crewSelectList` as a comma-separated value; the GOAT was sending repeated query params which PHP collapses to a single value.

   Affects both code paths:
   - Crew Finder UI "Send SMS" button
   - ASK THE GOAT "send SMS" tool

   No data migration or config changes required. Update via the in-app update prompt or download below.
