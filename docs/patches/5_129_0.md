# 5.129.0

*Released 27 November 2026*

New crew no longer receive a password by email. The welcome email now carries a one-time "Set your password" link that expires after 7 days, and Convert to crew, Update existing record and Add Crew Member no longer show a password. Resend welcome email sends a fresh link instead of resetting the password. Admins have a new Text reset link button on Edit Crew Member, which texts the crew member a 30-minute link to set a new Crew Hub password. For crew added with Add Crew Member, ask them to tap Forgot password in Crew Hub.
