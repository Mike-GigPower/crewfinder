# 5.46.0

*Released 15 September 2026*

The Licence Register arrives, in Administration.

Every licence on file, soonest expiry first, one row per crew member per licence.
It opens on 962 records across 534 people, 15 of them already expired.

Seven one-click filters: Expired, Expiring soon, No expiry recorded, Untriaged,
No code closed, Type says induction, Not on roster. Group by licence turns it
into holder lists, and Export CSV writes exactly the rows on screen with the
filter in the filename.

It deliberately does NOT hide crew who are off the active roster. Almost half
the licences on file belong to people whose roster flag is blank or inactive,
and somebody whose flag is wrong is exactly who you need to see.

Clicking a name opens that crew member's record.

Also: the licence catalogue is now readable by Operations and Leadership, not
admin alone.
