# 5.69.0

*Released 9 October 2026*

Today › Operations has a new Crew lists to send tile for admins. It counts calls with confirmed crew in the next 14 days whose crew list hasn't been sent, or has changed since it was sent.

The first donut shows how soon each call is due, counted in working hours: due in 24 working hours, 24–72 working hours, or later. Weekends and Victorian public holidays don't count, so a Saturday or Sunday call joins the 24-hour group from midnight Thursday. The second donut splits never sent from changed since sent.

Clicking the tile lists the calls grouped by booking, most urgent first. Each booking has **Create crew lists for these calls**, which opens Create Crew Lists with just those calls ticked, and **✉ Mark as sent**, which records lists you have already sent without printing them again. Calls drop off the tile as soon as they are marked.
