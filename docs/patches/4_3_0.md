# 4.3.0

*Released 16 July 2026*

What shipped


Inductions are now collected at onboarding, exactly like licences. The /details form gained an Inductions section that mirrors Licences one-for-one — repeating entries (venue + date + PDF), an Add another button, optional (never blocks Submit), and resumable through the same draft/rehydrate path. Entries save to cert_details.inductions.
The dropdown is the monitored-induction set, coded (Option B). 17 options, each storing a stable venue code (value) with a friendly label — the canonical INDUCTION_VENUE_MAP venues, with Melbourne Park as one grouped MELB_PARK option covering its five arenas. Hamer Hall added; the non-canonical strays (MCG - Gate 7, Crown - Palms, Jeffs Shed) removed. "Vaccination Status" stays excluded.
Convert-to-crew now brings the inductions across. When a candidate is converted, each onboarding induction is written into SmartStaff — a crew_venue_induction row (+ the matching user_licenses Induction Certificate row) per venue, with the PDF transferred from Supabase Storage onto the crew record. A MELB_PARK entry fans one certificate across all five arenas in a single write.
The convert modal reports each induction. A per-item outcome list beside the licence outcomes — ✓ added / • already on file / ✗ failed — so the operator sees exactly what landed. MELB_PARK shows as one "Melbourne Park" line.
