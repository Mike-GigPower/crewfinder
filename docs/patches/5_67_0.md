# 5.67.0

*Released 9 October 2026*

Administration now lists Victoria's public holidays, for this year and next, in a new Reference data section at the bottom. The list comes from the Estimator, so holidays are kept in one place: add or correct a holiday there, then click **Refresh** to see it in THE GOAT straight away.

If the Estimator can't be reached, THE GOAT shows the last saved copy and says so. An amber line also appears if a year's holidays haven't been added to the Estimator yet.

Nothing else changes in this release. The list is groundwork for the coming **Crew lists to send** tile, which counts working days and skips public holidays.
