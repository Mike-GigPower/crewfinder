# 5.116.2

*Released 20 November 2026*

The System tab now scrolls. Everything below Background — including the twenty slowest requests — was previously cut off with no way to reach it.

On a wide window the tab also uses the whole width: the graphs sit on the left, the grey stat boxes stack on the right, and the slowest requests run full width underneath. On a narrower window everything stacks into one column as before.

Silent re-logins used to appear twice. The small duplicate has gone; the two clear cards remain, and the "what does this mean" ⓘ now sits on that heading.

Layout only — no change to what is measured, how often, or what the numbers mean.
