# 5.81.0

*Released 22 October 2026*

Admins can now record which calls attract Broadcast and Travel, set a travel time for each venue, and group bookings into events. Nothing is priced from these yet: SmartStaff still bills and pays from its RATE column until THE GOAT's pricing goes live.

- **Allowances on calls:** the call's Details tab has Broadcast and Travel buttons (Admin only). Travel isn't offered on M&OP bookings; a call flagged before its booking moved to M&OP shows "not on M&OP" and keeps its flag.
- **Venue travel time:** the booking's Details tab shows the venue's return travel time, set in 15-minute steps. It's one figure per venue, used by every booking there. A Travel call at a venue with no time set shows "venue has no travel time" with a Set... link straight to it.
- **Events:** put a booking into an event (a whole festival or show run) from its Details tab, see the other bookings in the same event, and move or remove it. A booking is in one event at most.
- **Calls tab:** B and T markers show which calls carry Broadcast or Travel.
- **All Bookings:** expanded rows now have an Open booking link, so bookings with no calls can be opened too.
