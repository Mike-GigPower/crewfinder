# 5.73.0

*Released 9 October 2026*

Crew → Records now shows whether each crew member has a signed employment agreement on file. Admins only.

The new **Contract** column, after Push, shows the date the agreement was signed. It reads **On file (no date)** when no signing date was recorded, and **None** when there is no contract. A dash means THE GOAT couldn’t check, not that there is no contract. **· no PDF** in amber means the record exists but no PDF is stored. Hover the cell to see where the contract came from, for example **Imported from Drive (2025)**.

Click the **Contract** header to sort: crew with no contract come first. Click again to reverse.

Turn on **No contract** in the toolbar to see only crew without one. It shows in the count line, and **Clear filters** turns it off. If contract data couldn’t be loaded, the list says so instead of showing an empty or complete list.

Click any Contract cell to open that person’s record on the **Documents** tab, where **Load from Drive** is offered if they don’t have one yet.

**Export CSV** now includes a **Contract signed** column.
