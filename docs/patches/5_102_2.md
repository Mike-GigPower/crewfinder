# 5.102.2

*Released 12 November 2026*

Bookings imported from the Estimator now carry the quoted amount.

The Estimator's export gains a new version, 1.3, which includes the quote's totals and the billable hours behind them. When you import one of those files, THE GOAT reads the quoted amount straight off it and stores it against the booking, so the Financials tab shows **Quoted** without anyone typing it in.

The import preview shows it before you commit to anything: "Quoted: $38,801.80 ex GST (Estimator GP-000123, v2)". If the quote was exported with the four-hour minimums turned off, the preview and the Financials tab both say "(no minimums)" beside the figure, so it is never read as a like-for-like against one that had them.

Everything about older exports is unchanged. Files from versions 1.0, 1.1 and 1.2 import exactly as before and carry no quoted amount, so those bookings still get **Quoted** from an Admin on the Financials tab.

A few deliberate limits:

- The quoted amount is **ex GST**. The GST and inclusive totals in the file are read and checked, but not stored — the Financials tab is ex GST throughout, and keeping a second total in a different basis beside it would be asking for the wrong one to be quoted back.
- **Re-importing a revised quote does not update the figure.** Importing the same estimate twice is refused, as it always has been, and an imported amount still cannot be overwritten by hand. Making a revision update a booking is a separate piece of work.
- If the quoted amount cannot be saved for any reason, **the import is never undone**. The booking and its calls are created, and a red banner tells you to set the amount on the Financials tab.

A 1.3 file that is missing its totals, or has a line without billable hours, is refused with a plain message rather than imported half-right. If the file's own subtotal does not match its labour plus non-labour, the import still goes ahead and the preview says so, because that is the Estimator's arithmetic to explain, not a reason to hold up a booking.
