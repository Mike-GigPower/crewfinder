# 5.44.0

*Released 12 September 2026*

THE GOAT now carries its own documentation.

A new **Docs** area in the top bar holds user guides, technical guides and the full patch history, with search across all of it. Five guides cover Getting Started, Crew Finder, Create Booking, Inductions and Utilization. Three technical guides cover the architecture, the SmartStaff integration and the crew cache.

Patch history goes back to v2.0.0 — every release since 14 May 2026, 164 of them, grouped by major version and searchable alongside the guides.

Search matches every word you type, so "google sheet import" finds the release that fixed it and little else. Press `/` to jump to the search box; `⌘K` finds Docs by that name or by "help", "manual" or "changelog".

Admin, Operations and Leadership. Crew have Crew Hub.

App-only release — no SmartStaff or database changes.
