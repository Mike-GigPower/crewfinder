# 5.87.0

*Released 26 October 2026*

**Delete all feeds:** a booking's **Call feeds** tab now has a **✕ Delete all feeds** button (Admin only) that removes every feed on the booking, locked and recommended, in one go. It asks first, and nobody is taken off any call: crew already carried onto a call by a feed stay booked there. Crew boss assignments are not affected. Useful late in a multi-day booking when changes have broken the feed rules.
