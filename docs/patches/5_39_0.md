# 5.39.0

*Released 10 September 2026*

Creating a booking from a GigPower estimate no longer locks the imported call sheet. Every field on every call can now be edited before anything is written to SmartStaff — call name, date, start time, length, crew required and notes — and you can add a call the estimate missed or remove one that isn't happening.

The booking's own date follows whatever you end up with, so re-dating a call moves the booking to match.

In manual mode, call rows now take their date from the Booking Date. Change the Booking Date and any row you haven't re-dated by hand follows it, while a row you've deliberately set to another day is left alone. New rows start on the Booking Date instead of copying the row above.

Every date field now shows its weekday underneath — "Sat, 12 Dec" — so a wrong date is obvious before the calls are created.

Non-labour items from the estimate are unchanged: they're still created as "Other" calls and aren't edited here.
