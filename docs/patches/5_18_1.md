# 5.18.1

*Released 26 August 2026*

Booking numbers now work in both booking searches.

Type a booking number — with or without a leading # — into the Schedule
search or the Unfilled Calls search and it jumps straight to that booking.
Previously you had to already know the booking's name, which meant a
number from an invoice, a timesheet title or SmartStaff was useless in
THE GOAT's own search.

The number must match a booking exactly: typing 118 will not return
everything in the 11800s. If the digits match no booking, the search
falls back to matching names and venues as before, so nothing that
worked previously has changed.
