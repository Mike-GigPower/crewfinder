# 5.83.0

*Released 22 October 2026*

A backup who has been promoted but hasn't accepted yet now shows as Pending, the same as a backup who has been called out. They still hold the place.

- **Call dialog:** their status shows an amber PENDING badge instead of green CONFIRMED. Admins still see the "↑ promoted — not confirmed" tag beside it. The filter chips and status sort count them under Pending.
- **Confirming them:** admins can pick Confirmed from the status dropdown once they've spoken to the crew member. It asks the same "only if you've SPOKEN to them" question as clicking the tag. Cancel leaves them on Pending.
- **Crew Finder:** the Already Booked panel has a new Pending group for them. Their bars and tags read PENDING ("Promoted — awaiting reply"). A clash with the shift you're filling is still shown in red, because the place is held. "Hide booked" still hides them.
- Nothing else changes: capacity, the calendar, conflict checks, hours and forecasts still treat them as booked.
