# 5.13.0

*Released 23 August 2026*

THE GOAT now shows an amber strip across the top when it is pointed at a non-production SmartStaff server, naming the server. Nothing appears when it is on production.

ASK THE GOAT will no longer report a clean compliance sheet when it cannot read the induction data. If the crew cache is empty or holds no induction records, it says so and asks you to refresh, instead of answering with zeros. Its totals now come with the number of crew and records they were computed from.

The roster badge in the header no longer shows a reassuring green count when the cached roster holds no induction data.

Also fixes a crash that produced an unhelpful "Comms issue — 500" in ASK THE GOAT when the Anthropic key was missing or the config file was malformed.
