# 4.37.0

*Released 10 August 2026*

Crew who hold a valid induction for the booking venue now carry a green ✓ Current induction badge beside their name, alongside the existing amber and red ones. A line on the results bar names which of the searched venues are induction-controlled, so a crew member with no badge at that venue reads as a gap rather than an unknown.

Induction warnings now respect the Published flag. The whole check — green, amber and red — is gated on the induction catalogue's Published setting for the first time, so unpublishing an induction in Manage Inductions removes it from Crew Finder's assessment. If the catalogue can't be reached, checks continue against the built-in validity table rather than switching off.
