# 5.16.0

*Released 24 August 2026*

Selecting a customer on the Performance chart now recolours the chart to that customer's colour, so it's obvious which view you're looking at.

Customer colours are now stable. They were previously assigned by ranking position, so a customer's colour changed when the rankings moved or the window changed. They're now tied to the customer, and stay the same between sessions.

The notes explaining how the forward book is built now collapse, and stay collapsed. The unfilled-seats figure and its breakdown remain visible.

Chart hatching is now drawn in a fixed light stroke rather than a tint of the chart colour, so the uninvoiced and short-staffed markings stay legible on every colour.
