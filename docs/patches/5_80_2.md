# 5.80.2

*Released 22 October 2026*

Dates that start on "today" now use Melbourne time, so before 11am they no longer show yesterday's date.

- **Create Booking:** Booking Date now starts on today.
- **Add call:** the date now starts on today.
- **Crew unavailability:** the start and end dates now start on today.
- **Forecast:** today's column is highlighted correctly first thing in the morning.
