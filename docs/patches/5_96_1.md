# 5.96.1

*Released 9 November 2026*

Crew Finder fix: searching several calls at once now shows each call's booking correctly.

When someone is booked on only some of the calls you've selected, the timeline now shows a booked bar on just those calls, and each bar's hover names its own call with its own times. Previously a booking on one call was painted over every selected call, and every bar named the first call. The Availability column now says **BOOKED 1/2** (booked on 1 of 2 selected calls); the call pills underneath show which. Someone booked on every selected call still shows **BOOKED**.

Calls you're only considering (marked ~) no longer count as a booking on the calls you're filling, and a single-call search no longer draws the booked bar over considered calls.
