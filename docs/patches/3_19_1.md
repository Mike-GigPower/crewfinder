# 3.19.1

*Released 9 July 2026*

# THE GOAT — v3.19.0 → v3.19.1

Frontend only. No PHP, no backend changes.

## Change

The **Google Sheet** button on a booking now shows a **persistent popup** confirming the sheet was
created, with a **clickable link** to open it — replacing a 2.5-second toast plus an auto-opened tab
(which browsers could silently pop-up-block, leaving no sign anything had happened).

- **Success:** a popup titled "Google Sheet created" with a "📊 Open the Google Sheet ↗" link in the
  body and an "Open sheet ↗" button. Dismiss via the button, ✕, backdrop, or Escape.
- **Failure:** the server's error message now shows in the same persistent popup (was a fleeting
  toast, easy to miss).
- Removed the post-`await` `window.open(...)` (it sits outside the click gesture and gets silently
  blocked by pop-up blockers). The user now clicks the link — a real gesture that always opens.

Reuses existing infrastructure in `templates/index.html`: the shared `entity-modal`
(`openEntityModal`/`closeEntityModal`), `escapeHtml`, and the app's canonical in-modal link style.
No new elements, helpers, or CSS.
