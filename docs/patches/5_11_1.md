# 5.11.1

*Released 21 August 2026*

Licence types that never expire — a white card, for instance — now show a green "Held" marker on a crew member's Licences tab instead of nothing at all. A blank read as though the expiry hadn't been recorded, which is a different thing entirely.

The summary line above the list now counts those, so it matches the rows beneath it, and the Manage Licences confirmation dialogs describe what actually happens on screen.
