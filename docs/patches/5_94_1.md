# 5.94.1

*Released 9 November 2026*

"Crew send own times" is now off unless Ops tick it, on calls with no Crew Boss or Team Lead.

In the call dialog, the switch beside "Times by" now starts unticked. Ticking it turns self-submitted times on for that call; unticking it turns them off again. Calls that were never ticked stay off, and the line reads "Crew send own times — off".

Crew still can't send their own times until the feature is switched on in Crew Hub, so nothing changes for crew today. No SmartStaff changes in this release.
