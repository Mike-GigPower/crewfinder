# 3.0.0

*Released 20 May 2026*

## What's new in v3.0.0

**THE GOAT rebrand**
- New app name: The GOAT — Gig Power Operations and Administration Terminal
- New dark tactical UI — charcoal, gold accents, red alert states
- Cinematic animated login screen
- Bebas Neue / Rajdhani / Share Tech Mono typography

**Ask THE GOAT — AI Assistant**
- Natural language interface to SmartStaff data
- Live tools: unfilled calls, crew availability, inductions, forecast, import log
- Write actions: add crew to calls, send SMS (confirmation-gated)
- Conversation memory across page reloads
- Crew ID verification before any booking action

**Crew Utilization tab**
- 28-day resource forecast with daily heat bar
- Filter by name, group, star rating
- Configurable day range (1–28)

**Estimate Import tab**
- Import GigPower Estimator JSON payloads
- Auto-creates SmartStaff bookings and calls
- Fuzzy customer/venue/contact matching
- Duplicate detection and import history log
