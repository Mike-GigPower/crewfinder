# 5.66.1

*Released 8 October 2026*

Crew Finder's Search button now shows the call name as well as the number. With one call selected it reads, for example, **Search #39050 General**. Long names are shortened with "…", and hovering over the button shows the full name. With two or more calls selected the button still reads **Search N calls**.

The label above the Crew Finder results now shows call names containing an ampersand or an apostrophe correctly, instead of stray codes in place of those characters.
