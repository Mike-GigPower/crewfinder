# 5.74.1

*Released 15 October 2026*

A backup who has been promoted to Confirmed but has not yet accepted can no longer have times entered for the call.

- **Enter Times:** their row is greyed out and tagged PROMOTED · NOT ACCEPTED. The fill-down arrow and Save both skip them, so copied times can no longer land on someone who didn't work.
- **They did work?** Use "they worked — unlock" on the row (or dismiss the amber pill on the call). Only do this if you have spoken to them. It is recorded as an ops confirmation.
- **Already has times saved:** if a locked person already has times stored, they are named in amber so they can be checked before the pay run.
- **Import Times:** promoted, unaccepted crew on the Google Sheet are shown locked and are not written. Any row SmartStaff refuses is now named in the result instead of silently missing from the count.

SmartStaff itself now refuses these times too, including on its own call sheet times page.
