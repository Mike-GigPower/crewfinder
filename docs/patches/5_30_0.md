# 5.30.0

*Released 4 September 2026*

The Visa Register can now be grouped by visa subclass and exported to CSV.

Group by subclass — a toggle beside the filter chips. Groups are ordered
largest first, and anyone whose subclass hasn't been recorded is shown last
rather than hidden. Grouping composes with the filters, so Expired plus
grouping answers "which subclasses do the expired people hold". The default
view is unchanged: everyone, soonest expiry first.

Export CSV — downloads exactly the rows on screen, so an Expired export
contains only the expired ones, and the filename records which view it came
from. The file carries EIN, name, roster flag, subclass, grant and expiry
dates, days to expiry, work limitation, conditions, VEVO status and whether a
visa document is on file. Passport numbers and TRNs are deliberately left out —
those stay on the individual crew record.

The Inductions export now shares the same CSV writer, so accented names no
longer come through garbled in Excel.
