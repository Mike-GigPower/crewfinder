# 3.1.0

*Released 21 May 2026*

## What's new in v3.1.0

**📅 Schedule Tab**
- New landing tab showing all bookings for the next 14 days
- Staffing status: Full (green) / Partial (amber) / Unfilled (red)
- Collapse/expand bookings, All/Open filter, booking search
- Date range, venue, and staffing summary on each booking header
- Today column highlighted and wider
- Notes visible in timeline blocks
- Confirmed/unconfirmed/waiting/declined status on expand
- Quick actions: Find Crew, SMS, Open in SmartStaff per call

**⚡ Crew Finder improvements**
- Already Booked section at top of results showing crew status
- Stale results greyed out when call selection changes

**🐐 Ask THE GOAT**
- Conversation memory across page reloads
- Crew ID verification before booking actions
- Fixed write action confirmation flow

**🛠 Bug fixes**
- Estimate Import restored
- Performance improvements
- Version number displayed in nav bar
