# 5.86.0

*Released 23 October 2026*

**Plan a whole booking:** in Crew Finder, select a booking's calls (or use **Select all**) and press **Plan N calls…**. THE GOAT plans every call, keeps the same crew across load-in, show and load-out wherever they can work them, holds a load-out's places for the crew its load-in carries there, and never double-books anyone, including against offers they already hold on the booking. A review shows each call's picks; **Add plan** sends it all in one go, with the usual over-warnings and a results summary. Plans now explain "0 places" (for example "9 confirmed, 5 offers awaiting reply"). In Ask the GOAT, a staffing plan now shows a read-back card to confirm before anything is planned, and the Open in Crew Finder button sits under the answer.
