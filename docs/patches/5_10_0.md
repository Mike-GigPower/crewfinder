# 5.10.0

*Released 20 August 2026*

The licence taxonomy now lives in a database table rather than being hardcoded in five places across two repositories. Behaviour is unchanged — the same 41 licence types, the same expiry rules — with the constants retained as a fallback if the table can't be read.

One visible change: licence type dropdowns in Manage Crew and Crew Hub now list types in order of how often they're used, so Forklift and Construction Induction appear near the top rather than Basic Scaffolding.

Groundwork for an admin editor, which follows in a later release.
