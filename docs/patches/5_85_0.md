# 5.85.0

*Released 23 October 2026*

Admins can now open any call or booking straight from its number, whether it's filled or not and however old it is.

- **⌘K:** type a call or booking number and press Enter. If only one thing has that number it opens straight away. Some numbers belong to both an old call and a booking; then both are listed, call first, and you pick.
- **Crew Finder and Schedule searches:** typing a number that isn't in the list shows a "Not in this list — look up #…" link that opens it.
- **Ask the GOAT:** "open call 38965" (or booking) finds it and puts an Open button under the answer. Nothing opens until you click it. "Plan call …" now finds the booking the same way, so it also works for calls more than 10 weeks away.
- Admin only, like the call dialog.
