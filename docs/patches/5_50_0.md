# 5.50.0

*Released 17 September 2026*

A row in the Crew Reliability Red Zone now opens to show what the person actually did.

Click a name and the row expands to list their incidents across the twelve months behind the register — the date and start time, the booking and the call, and whether it was a no-show or a late. Most recent first.

Until now the tile named people and stopped there. A name beside a percentage invites an argument about the number; a name beside four dated calls is something you can have a conversation about.

Two incidents on the same day are ordered by start time, so a late finish at a 10pm load-out sits above a no-show at that morning's load-in rather than falling wherever the database happened to put them.

Nobody's access changed. The expansion reads the same Red Zone data behind the same permissions as the rest of the lane — there is no new screen, and nothing that opens for one person and not another.

Also fixed: crew names that carried a stray trailing space now read cleanly.
