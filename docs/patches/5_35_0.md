# 5.35.0

*Released 8 September 2026*

The Convert to crew modal now pre-fills First name and Last name with what the
applicant actually typed, rather than guessing the split from a single name field.

Both application forms started asking for first and last name separately this
week, so for anyone applying from now on the split is their own answer — the
modal says so, and there is nothing to correct.

Older applicants, and the 57 people who only ever gave a one-word name, still
need the split derived. The modal now flags those in amber so you know which
ones to read before creating the record.

Nothing else changes. Convert sends exactly the same fields to SmartStaff, and
you can still edit either name before creating the crew member.
