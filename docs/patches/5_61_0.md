# 5.61.0

*Released 23 September 2026*

THE GOAT now shows when a booking already has a Google Sheet timesheet. In the booking dialog, a new Google Sheet section lists each sheet with the time it was made and an Open link. In All Bookings, the Google Sheet button turns amber and reads Sheet exists.

If you click Generate Google Sheet on a booking that already has one, THE GOAT asks first: open the existing sheet, create another anyway, or cancel. This works across every Ops machine, so a sheet made on someone else's Mac is found too. Moving a spare sheet to the Bin in Google Drive clears it from the list.
