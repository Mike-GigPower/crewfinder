# 5.45.0

*Released 14 September 2026*

Crew → Records can now be filtered by licence.

- A new Licence picker on the Records toolbar, with the same grouped chips and holder counts as the Crew Finder's licence filter. Tick one or more codes and the roster narrows to crew holding all of them. Each matching row shows the codes it matched on, and an expired ticket is badged.
- Driver classes match upward: filtering on MR also returns HR, HC and MC holders.
- Holder counts describe the active roster, so they are hidden while the Inactive set is showing.
- If licence data is unavailable, the filter says so rather than quietly returning an empty list.

Also fixed: adding or deleting a licence type now updates the Crew Finder chips and the Manage Crew dropdowns without quitting THE GOAT.
