# 4.15.0

*Released 30 July 2026*

The Crew Lists dialog now remembers what you picked last time — which optional
columns to include (EIN, Phone, Email), and whether to list confirmed crew only
or everyone rostered.

Choices are remembered per person rather than per machine, so changing your own
defaults never changes anyone else's. Selections are stored on your own Mac.

A fresh install still starts with Phone and Confirmed crew only.
