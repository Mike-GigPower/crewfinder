# 5.6.0

*Released 18 August 2026*

Crew Finder can now filter by licence. Pick one or more licence types and the search returns only crew who hold them, with a pill on each result showing what they hold and whether it's current.

Driver classes understand seniority: filtering for Medium rigid also returns crew holding Heavy rigid, Heavy combination or Multi combination, since a higher class covers a lower one.

A "only show valid on the call date" toggle hides crew whose licence has expired by the date of the call, and reports how many were hidden. A licence with no expiry recorded is treated as valid for now — the pill shows which is which.

If licence data can't be loaded, the filter says so rather than quietly returning an empty search.
