# 5.9.0

*Released 20 August 2026*

Recruitment's Operations, Dashboard and Sessions are now proper tabs in the navigation bar, sitting where Crew's Utilization, Inductions and Records do. Each has its own address, so you can link straight to one, and the app remembers which you were last on when you come back to Recruitment.

Nothing moved inside the three views — same applicant list, same dashboard, same session management.

Also fixed: the applicant search box and session dropdown sit side by side again instead of stretching the full width of the page.
