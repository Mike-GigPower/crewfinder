# 4.35.0

*Released 10 August 2026*

Calls tab now shows which calls a crew member was late for. The reliability header has counted late incidents for a while; each one is now marked on the call it belongs to, with a running total in the summary line.

Booking details call rows now carry their start date and time. Bookings with several identically-named calls — three or four "Load In" rows — are readable at a glance, including when setting up call feeds.

Status pills say what they mean. No-shows and backups previously rendered as "Status 8" and "Status 7" on the Calls tab.
