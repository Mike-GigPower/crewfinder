# 5.36.0

*Released 8 September 2026*

The Calls to fill card on the ops landing page now has a Donuts / Calendar switch.

Calendar shows a month at a time. Each date carries the crew assigned in the top left and the crew required in the bottom right — green when the day is fully crewed, amber when it's partly filled, red when nobody is booked yet. Use ‹ › to move between months.

Clicking a date opens the usual drill-down, filtered to that day's calls still needing crew. Days that are already fully crewed, and days before the current window, show their numbers but aren't clickable.

One thing worth knowing: the calendar counts every call starting that day, including ones already fully crewed, while the number in the card's badge still counts only the calls needing crew. The two will often differ, and that's deliberate.
