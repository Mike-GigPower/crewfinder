# 5.72.0

*Released 9 October 2026*

Signed employment agreements already in Google Drive can now be loaded onto crew records. Admins only.

**Manage Crew → Import contracts from Drive** reads the Completed/Signed folder and suggests a crew member for each PDF from the name in its title. Click **Scan Drive** to see every agreement sorted into Exact, Likely, Ambiguous, No match and Already on file. TFN, visa and VEVO files are skipped and counted. Exact matches start ticked. Everything else waits for you to tick it, and you can pick a different crew member on any row that isn't an exact match. Use **Preview** to open the PDF in Drive and check it's signed before you save.

Next to the filters, **Tick all exact** ticks every Exact match that isn't already on file, and **Untick all** clears every tick, including rows the current filter is hiding. One crew member can never be ticked on two rows.

**Save** works through the ticked rows one at a time and marks each one Saved, Already on file or failed. One failure doesn't stop the rest. If someone has more than one PDF, the latest-signed one is suggested and the others are listed under it, so you can swap.

When a crew member has no contract on file, **Manage Crew → Documents** now shows **Load from Drive**. It lists Drive PDFs carrying their surname, and you can search for any other title.

Imported contracts show the signing date from the filename, are labelled **Imported from Drive**, and also appear in the crew member's own Crew Hub My Documents. A saved contract can't be replaced or removed from THE GOAT.
