# 4.11.0

*Released 24 July 2026*

## Call feeds

Calls can now depend on each other directionally. Crew booked on a load-in
are automatically offered the load out — but not the reverse, so a 5-person
show call can feed a 20-person load out without needing all 20 free for the
show.

A load out can be fed by **several** load-ins, which the old linked-calls
model couldn't express. The Laufey shape — four staggered load-ins feeding
one 54-person load out — now works as one relationship.

**Setting them up.** The 🔗 Link calls button in the booking dialog is now
**⇢ Call feeds**. It's two-step, because direction matters: pick the call
crew come *from*, then tick the calls they should also work. Feeds are
removed individually.

You'll be warned, but not blocked, if the calls overlap in time, if the
receiving call would be over-subscribed, or if the feed is redundant.

**Crew Finder.** Selecting a call also selects everything it feeds — shown
with a dashed edge so you can tell what you picked from what came along.
Availability is checked across all of them, so crew who can't do the load
out won't appear for the load-in.

Calls with feeds show their slot maths: **20 required · 15 reserved · 5 to
fill** — the reserved ones being held for crew coming from upstream.

**For crew.** Accepting a load-in accepts the load out with it, one tap.
Declining the load out also releases the load-in, since they can no longer
do it — and that's the first thing in the system that takes a shift back,
so it asks first.

## Existing linked calls

Unchanged in behaviour. They now show as both "feeds 1" and "fed by 1" on
each call — that's what a two-way link looks like in the new model, not a
fault.

## Also fixed

- **Offers that clashed with an already-confirmed shift used to fail
  silently.** No row was created and the Finder still reported success.
  Failures are now shown per crew member with the reason.
- Crew who have already confirmed, been made backup, or been marked no-show
  are no longer told the call is on offer. Crew who haven't answered still
  are — chasing them still works.
- Adding someone who's already on a call no longer resets their status and
  orphans their calendar entry. They're left alone and reported as skipped.
- Offers are sent in one request per crew member rather than one per
  crew-call pair, so large calls go out faster.
- Apostrophes in call names render correctly in the booking dialog.
