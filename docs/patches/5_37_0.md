# 5.37.0

*Released 9 September 2026*

Crew who trip a fatigue, venue-change or 24-hour-load rule are no longer hidden from Crew Finder. They now appear as available with an amber ⚠ and the reason beside them, so you can judge whether it's workable — a spot operator rolling into their own load-out, or a walk between two gates at the same stadium, are calls for ops to make, not the system.

Genuine double-bookings and unavailability still block, exactly as before. The Finder now refuses precisely what SmartStaff refuses at write time, so it can no longer offer you someone the add would reject.

Select All skips warned crew — those have to be ticked deliberately.

The minimum-rating filter now opens at 1 rather than 2, so new starters appear in a default search. Previously a fresh load was stricter than clicking "Clear all filters".

THE GOAT's assistant applies the same rules and will mention warnings when it names someone.
