# 3.3.1

*Released 27 May 2026*

v3.3.1 release notes:

Fixed — Non-labour item call names now use the item title ("Harness Hire") instead of "Other" in SmartStaff. SmartStaff's call_name_hidden field is what controls the displayed call name; the select value is now bypassed correctly.
Fixed — Call names from the JSON file now pass import validation regardless of whether they appear in the VALID_CALL_NAMES list. Only operator-manually-entered names that aren't in the valid set are rejected.
Fixed — Import call name dropdown now pre-selects JSON call names even when they're not in the standard picklist, with the item name shown as an extra option at the top.
Improved — Running goat animation now shows during file validation on the Estimate Import tab so it's clear something is happening. 🐐
