# 5.80.0

*Released 21 October 2026*

Accreditation photos: download a zip of the confirmed crew's photos for a booking, named the way the venue or promoter asks.

- **Where:** 🪪 Accreditation photos in the booking dialog, and 🪪 Photos (zip) in Create Crew Lists, which carries over the calls you ticked. Admin only.
- **Name format:** pick a preset (jane_smith, j.smith, Jane Smith, SMITH_Jane, jane_smith_3315) or type your own, e.g. {LAST}-{f}. A preview shows how the first name will look. The last format you used is remembered on this Mac.
- **Best photo available:** the full-size onboarding photo where we have one, otherwise the small SmartStaff photo, marked low-res.
- **Nobody holds it up:** crew with no photo are left out of the zip and listed, so you can chase them.
- **Two people with the same name** get their EIN added to the file name.
- **_summary.csv** in the zip lists everyone, their file and the kind of photo. Untick it to leave it out.
