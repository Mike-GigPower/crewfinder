# 4.19.1

*Released 5 August 2026*

Crew Notes is now available directly from the call dialog, not just the booking dialog.

Opening it from a call lands you on that call's notes panel in the Crew Hub — already expanded, highlighted and scrolled into view. Previously the only route was the booking-level button, which opened the booking with every call collapsed, making the booking-wide note box the easiest one to type into. A note meant for one call posted there reaches every crew member on the job.

The booking-level button is unchanged.
