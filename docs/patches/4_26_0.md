# 4.26.0

*Released 6 August 2026*

Needs attention is now a toggle inside each pile rather than a pile of its own. Every pile chip carries its own count of candidates needing chasing, so you can see where the work is without switching views.

New flag for working-visa applicants whose VEVO check hasn't been recorded.

The generic "Waiting N days" flag no longer draws its own chip — the amber "N days in stage" label beside it already said the same thing. Those candidates are still counted in the pile totals.
