# 5.96.2

*Released 9 November 2026*

Crew Finder fix: the timeline hover now shows the call's real venue.

Hovering the bar for the call you searched could name the wrong venue — call #39519 at AAMI Park showed MCEC. THE GOAT now reads each call's date, times and venue from the booking itself instead of reading SmartStaff's call page, and when you search several calls each bar names its own venue.

Calls opened by number (look up #ID) now get the same induction check as calls picked from the Unfilled Calls list, so you may see "Induction required" on calls that didn't show it before.
