# 5.38.0

*Released 9 September 2026*

The booking dialog is wider, and every call in it now shows its notes from
SmartStaff in full, under the call name — the site instructions you'd otherwise
have to open each call to read. Only the booking dialog changed width; every
other dialog is as it was.

Dialogs now nest. Open a call from a booking and ✕ or Esc takes you back to the
booking, scrolled exactly where you left it, instead of closing everything — and
there's a "‹ Back to booking" button as well. It goes deeper too: Enter Times,
Responses, Crew Notes, Stand down and Edit call all step back to the call they
came from. Close still closes outright, in one click, from anywhere.

A call opened straight from the Schedule or Crew Finder has no parent to go back
to, so ✕ closes it exactly as before.
