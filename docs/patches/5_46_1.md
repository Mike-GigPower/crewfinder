# 5.46.1

*Released 15 September 2026*

Crew Finder's search box now finds calls, not just bookings.

Type a call name — Bump In, Rigging, Show Call — and the Unfilled Calls list
narrows to the bookings that have one, showing only the calls that matched. The
booking header stays as context, so you still know whose call it is.

Booking name and #id work exactly as before, and both still bring back the whole
booking: if you asked for a booking, you get all of its unfilled calls.

A booking you had collapsed opens itself when the search finds a call inside it.
A hit you cannot see reads as no result at all.

Venue is not searched — booking name, call name, and #id only.
