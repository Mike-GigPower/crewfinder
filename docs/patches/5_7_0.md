# 5.7.0

*Released 19 August 2026*

Ops can now record which crew boss call covers which calls, from the booking dialog.

Where that's set, crew asking "who do I ring?" get one correct name instead of every boss whose call happens to overlap in time. Bookings without it behave exactly as before.

Calls show who bosses them and what they boss, and a booking with a crew boss call warns when some calls have none assigned.
