# 5.56.0

*Released 21 September 2026*

Docs Centre can now show screenshots, and the Crew Finder guide is the first to use them.

**The Crew Finder guide has been rewritten end to end** and illustrated with fifteen screenshots. It covers picking the call, what every filter actually does, which rules block a booking and which only warn, open offers, reading a crew row, getting the most schedule onto the screen, reading the timeline, and booking — with a quick-reference table at the end.

Three things the old guide had wrong are now right:

- The Unfilled Calls box searches **call names** as well as booking names and #ids.
- Results come back **inducted-first** for the venue you are filling, then by rating.
- **Open-offer clashes** — the envelope marker after a crew name — were not in it at all.

It also now says plainly that Send SMS is not currently active, and that declines, which SmartStaff used to treat as hard conflicts, have been relaxed to warnings.

You will find it under **Docs** in the top bar, and it is searchable along with every other guide.

Under the hood, the documentation renderer supports images for the first time. Any guide can now include a screenshot, so the technical guides can use them too. Images are served from inside the app only — a document cannot make THE GOAT fetch anything off this machine.
