# 5.40.0

*Released 10 September 2026*

Importing times from a Google Sheet no longer quietly skips a call tab.

Until now THE GOAT decided whether a tab was a call by looking at one cell —
the "GOAT Call ID" label in A1. If a crew boss deleted that label while tidying
the sheet, the entire tab was filed under "Ignored support tabs" alongside
DATA LIST, and every crew member's times on it were dropped without a word. On
booking 11952 that cost a full call of 79 crew their times.

What changed:

- If the A1 label is missing but the Call ID is still in B1, the tab imports
  normally and the review tells you the label is worth restoring.
- A tab that clearly is a call tab but carries no Call ID at all — usually one
  built by hand — now gets its own warning and a dropdown of the calls that
  share crew with it, so you can map it yourself.
- Two tabs carrying the same Call ID are both blocked and named. Previously both
  were written and the second silently overwrote the first.
- A generated call tab nobody filled in is now listed, rather than vanishing
  from the review entirely.
- Uploading a finished .xlsx now maps by Call ID as well, which it has claimed
  to do since 3.14.0 but never did.

Genuine support tabs — DATA LIST, Schedule, Master and the rest — are unchanged.
