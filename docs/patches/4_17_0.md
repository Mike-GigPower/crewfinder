# 4.17.0

*Released 3 August 2026*

v4.17.0 — Induction Catalogue Phase 2: Manage Inductions

New: the induction catalogue is now editable in-app. Administration → Records → Manage Inductions lets admins add, edit, and remove major-venue inductions — validity periods, covered venues, crew/ops notes, links, and Checker/publish visibility — without touching the database.

Added
Manage Inductions editor (admin-only): create, edit, and delete catalogue entries.
Set validity in months or years, with a live impact preview before changing an existing validity — shows how many crew would be re-dated (→ Expired / → Expiring Soon) before you commit.
Assign covered venues via a multi-select; conflicts (a venue already under another induction) are flagged clearly rather than failing silently.
Per-induction crew notes, internal ops notes, and typed links (register / sitemap / info / parking / contact).
Guarded delete: an induction with completion history can't be hard-deleted — it offers Unpublish + remove-from-Checker instead, preserving records.
Induction codes are set once at creation to protect downstream references.
Changed
Retired the internal "Vaccination Status" exclusion now that vaccination records have been removed from the system.
