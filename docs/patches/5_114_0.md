# 5.114.0

*Released 20 November 2026*

Crew Finder now checks inductions by venue, not by venue name, so renaming a venue in SmartStaff can no longer switch its induction check off.

When Crown Melbourne - Palms was renamed Crown Live, calls there silently lost their induction badges. Crew Finder and Ask the GOAT now look up each call's venue in the induction list itself, which is kept by venue rather than by name, so a rename makes no difference.

- **Two more venues are checked.** Calls at the Arts Centre and the Royal Exhibition Building now show induction badges. Both were in the induction list but Crew Finder never recognised them.
- **One induction counts across the venues it covers.** A current Melbourne Park induction now shows as current on any of its five arenas, and the Arts Centre and Hamer Hall count for each other, matching the induction list. Previously each arena was checked on its own.
- **Ask the GOAT agrees with Crew Finder** when asked whether crew on upcoming calls are inducted.
- **Manage Inductions:** match keywords can now be entered one per line as well as comma-separated.
