# 5.52.0

*Released 17 September 2026*

Ops can now see an induction waitlist in the order it will actually be emailed.

Open a session's roster and the waitlist underneath it is ordered the way a freed seat is really offered: anyone who has never been emailed comes first, in the order they joined, then whoever was told longest ago. Each person shows their place in that queue, and the date they were last emailed if they have been.

A freed seat emails the first twenty people on the list. Where a list runs longer than that, everyone below the line is dimmed and a note says how many of them will not hear about the next seat.

Until now the list was ordered by when people joined. That is not the order they are contacted once anyone has been emailed, so the queue on screen could quietly differ from the queue in the system.
