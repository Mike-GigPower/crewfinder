# 5.117.0

*Released 20 November 2026*

Admins can now open a booking's Crew Hub check-in sheet straight from THE GOAT. On a booking using live check-in (Shadow or Live), an "Open check-in sheet" link appears in the booking dialog, the call dialog and Import Times.

Today › Bookings & Calls has a new Check-in today list showing every booking on check-in with a call today, with a link to each sheet. Import Times now mentions the check-in sheet first on bookings that use it.
