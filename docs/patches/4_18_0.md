# 4.18.0

*Released 3 August 2026*

Adds a Crew Notes button to the booking dialog, opening that booking's
Schedule popup in the Crew Hub where crew-facing notes are composed.

Crew Notes are a Crew Hub feature: messages attached to a booking or call
that appear on the shift card of every confirmed crew member, optionally
requiring a read-and-understood acknowledgement. The compose UI stays in
the portal so the feature can iterate without a DMG rebuild each time.
This button removes the context switch of leaving THE GOAT to find the
right booking.

Note that the existing Notes field in the booking dialog is unchanged and
remains operations-only. It is not shown to crew.

Visible to admin, operations and leadership.
