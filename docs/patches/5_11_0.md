# 5.11.0

*Released 21 August 2026*

Administration → Records → Manage Licences. Add, edit and remove licence types, set which group they belong to, and record whether a licence expires — either from a date printed on the card or a fixed period from the issue date.

Changing how a type is treated shows what it does to the crew who hold it before anything is saved. A type that crew already hold can't be deleted; unpublishing it keeps their records readable while removing it from searches and entry forms.

Two settings are recorded but not yet acted on when a licence is entered — whether a certified date is required, and the fixed validity period. Both are labelled as such in the editor, and will start applying in a later release.
