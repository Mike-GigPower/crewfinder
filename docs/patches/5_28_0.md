# 5.28.0

*Released 3 September 2026*

The signed employment agreement now has somewhere to be seen.

Convert-to-crew has been pushing every new crew member's signed contract into SmartStaff since February, but nothing could read it back — the document existed and was unreachable from the person's own record. Manage Crew now has a Documents tab showing it: the date they signed, the contract version, and a View link that opens the PDF.

Admin only — Operations and Leadership don't see the tab at all.

Read-only by design. The only writer is convert-to-crew, which is idempotent per crew member, so there's no upload control here to put a second contract of unknown provenance beside the signed one.

Crew who predate onboarding show "No documents on file", which is the normal state for most of the roster.
