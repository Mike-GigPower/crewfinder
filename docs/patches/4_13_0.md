# 4.13.0

*Released 29 July 2026*

Call feeds can now be set as recommended instead of locked.

A locked feed means crew booked on one call are committed to another — they're offered both together and answer as one. That's how all feeds have worked until now, and every existing feed stays exactly that way.

A recommended feed is softer: crew from the first call are preferred for the second, but the two calls are offered and answered separately. A crew member can accept the load in and decline the load out.

Creating one: in the booking dialog, open Call feeds, pick the call crew come from, tick the calls they should also work, then tick "Recommended only" before saving. The button changes to Save recommended so you can see which kind you're about to create.

Reading them at a glance:

Locked feeds show as solid chips — ↓ feeds 2, ↑ fed by 3
Recommended feeds show as dashed chips — ↓ suggests 1, ↑ suggested by 3
A call with both shows both chips

In the counts, slots held by a recommended feed appear as likely rather than reserved — 20 required · 8 likely · 9 to fill. Both are subtracted from "to fill", so the number of people you still need to book is unchanged.

Not in this release: the Crew Finder still filters on recommended feeds the same way it does on locked ones. Ranking crew by how many of the selected calls they're free for comes in a later update.
