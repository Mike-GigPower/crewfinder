# 5.113.0

*Released 19 November 2026*

Accounting › Invoicing can now create invoices (Mike only for now).

- **Ready to invoice:** bookings with locked, uninvoiced work in the last 12 months, grouped by customer, with each booking's calls and expected amount. Tick "Include older" to see earlier bookings.
- **Generate invoice** creates the invoice with SmartStaff's own invoicing, so the amounts are the same as SmartStaff's. The new invoice opens straight away, and it goes out in the next Xero export from SmartStaff as before.
- The confirmation shows the calls and the amount, and warns when some of the booking's calls aren't locked yet and will need a second invoice.
- **Safe to click twice:** if a booking has already been invoiced, or its calls changed since you looked, Generate refuses and shows what changed instead of creating a duplicate or an empty invoice.
- A booking with a call stuck on an earlier invoice is shown as blocked, with the reason, and can't be generated until it's fixed.
- Every invoice now has **Open in SmartStaff**, and the invoice window uses its full width, so every column shows.
